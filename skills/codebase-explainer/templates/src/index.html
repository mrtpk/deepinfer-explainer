How to use this site

  • Levels. Each page has a level: Beginner, Intermediate or Advanced.
  • Two depths on each page. A page starts with a plain explanation and a diagram. Then it shows the real code. Deep dive boxes give the full detail.
  • Check yourself. Most pages end with 3 to 5 questions. Click "Show answer" to see the answer.
  • Search. Press /, then type a word, a file name or a setting.
  • Glossary. Words with a dotted line, such as {{term kv-store}}, have a short definition. {{link reference/glossary}} lists all terms.
  • Code. The build copies every code excerpt from the repository. Every {{term citation}} opens the file at commit {{project short_sha}}.
