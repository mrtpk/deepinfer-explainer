Purpose

This page shows every folder of the repository. Click a folder name to open it at the pinned commit. Folders with a module page have a link to it.

The folder tree

Run python3 tools/gen_folder_tree.py to fill in the tree.

How the numbers were measured

The tool lists the tracked files with git ls-tree at the pinned commit. It counts the lines of text files. It does not count binary files.
